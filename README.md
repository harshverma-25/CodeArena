# DSA Tracker — Coding Progress Management Platform

A full-stack coding interview preparation platform designed to help developers track progress across popular DSA sheets and stay consistent during interview preparation.

Built using the MERN stack with secure authentication, progress analytics, and persistent tracking workflows.

---

## 🚀 Features

* 📚 Track progress across popular coding sheets
* ✅ Mark problems as solved
* 📊 Interactive progress analytics dashboard
* 🔐 JWT-based authentication & protected routes
* 💾 Persistent progress tracking across sessions
* 📱 Fully responsive modern UI
* ⚡ RESTful API architecture
* 🎯 Topic-wise preparation tracking

---

## 🛠️ Tech Stack

### Frontend

* React.js

### Backend

* Node.js

* REST APIs
